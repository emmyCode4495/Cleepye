# Nigeria payments (Flutterwave → Paystack → Korapay)

## Plans (NGN / month)
- Starter ₦10,000 — 8 credits, 1 device
- Creator ₦20,000 — 20 credits, 2 devices (recommended)
- Pro ₦35,000 — 40 credits, 3 devices, unlimited clips/mine

1 credit = 1 mining job.

## Env
FLUTTERWAVE_SECRET_KEY=
PAYSTACK_SECRET_KEY=
KORAPAY_SECRET_KEY=
PAYMENT_REDIRECT_URL=https://your-app/pricing?paid=1

Checkout uses the first configured provider that succeeds.
